<h1 align="center">Muhammad Usman — Portfolio</h1>

My personal portfolio as a Machine Learning Engineer and AI Developer. Built with [Remix](https://remix.run/), [Three.js](https://threejs.org/), and [Framer Motion](https://www.framer.com/motion/). Source available at [github.com/mhusman123/Portfolio](https://github.com/mhusman123/Portfolio).

## Install & run

Make sure you have nodejs `19.9.0` or higher and npm `9.6.3` or higher installed. Install dependencies with:

```bash
npm install
```

Once it's done start up a local server with:

```bash
npm run dev
```

To view the components storybook:

```bash
npm run dev:storybook
```

## Deployment

The site is configured for Cloudflare Pages. Deploy with:

```bash
npm run deploy
```
