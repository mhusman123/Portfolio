## Executive Overview & Research Motivation

### 1. Multi-Model Socratic AI Tutor (`/ai-tutor`)

Standard instruction-tuned LLMs immediately collapse the problem-solving journey by outputting complete answers. In contrast, the EduPlatform Socratic engine enforces **scaffolded cognitive inquiry with zero spoilers**.

![Socratic AI Tutor guiding a student through step-by-step calculus proofs with LaTeX formula rendering](/static/sst-ai-tutor.jpg)

#### Formalized Socratic State Machine:
At dialogue turn `t`, given student input `x_t` and historical context `H_{t-1}`, the system generates guidance `(q_t, hint_t)` rather than final answer `A`:

```text
P(output = A | H_{t-1}, x_t) → 0
Entropy(A | q_t) > τ_cognitive
```

The model identifies the student's exact point of breakdown in the derivation graph and formulates a diagnostic checkpoint prompt, requiring active synthesis before proceeding.

#### Architectural Highlights:
- **Multi-Model Dynamic Routing:**
  - **Google Gemini 1.5 Flash:** Low-latency streaming (`< 800ms` time-to-first-token) via Server-Sent Events (SSE).
  - **DeepSeek-R1:** Dedicated chain-of-thought (CoT) reasoning for step-by-step symbolic mathematics, calculus proofs, and algorithmic proofs.
  - **OpenAI GPT-4o-mini:** Qualitative synthesis, language parsing, and conversational humanities tutoring.
- **Scientific & Mathematical Typesetting:** Complete KaTeX / LaTeX rendering for differential equations, organic chemistry structures, and multi-language programming code blocks.

### 2. Adaptive Timed Quiz Arena & Exam Simulator (`/quiz-generator`)

To prepare students for competitive entrance exams (CAIE, MDCAT, ECAT, SAT), the Quiz Arena generates timed examination sessions parameterized by dynamic difficulty tiers.

![Adaptive Timed Exam Simulation Arena with active countdown, question shuffling, and topic scorecards](/static/sst-quiz-arena.jpg)

#### 3-Tier Timed Presets:
- 🏃 **Quick Sprint:** 20 Questions (Time Limit: 10 Minutes)
- 📋 **Standard Assessment:** 35 Questions (Time Limit: 17 Minutes)
- 🏆 **Comprehensive Exam:** 50 Questions (Time Limit: 25 Minutes)

#### Zero-Collision Randomization via Fisher-Yates Shuffling:
To eliminate question repetition and distractor sequence memorization across consecutive attempts, question arrays are shuffled using an in-place Fisher-Yates algorithm:

```typescript
function fisherYatesShuffle<T>(array: T[]): T[] {
  const result = [...array];
  for (let i = result.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [result[i], result[j]] = [result[j], result[i]];
  }
  return result;
}
```

This guarantees an unbiased uniform distribution over all `n!` permutations:

```text
P(π) = 1 / n!    ∀ π ∈ S_n
```

#### Dynamic Item Response Theory (IRT) Scaling:
Each question item `j` has an estimated discrimination parameter `a_j` and difficulty parameter `b_j`. The probability of a student with latent ability `θ_i` answering correctly is modeled via a 2-Parameter Logistic (2PL) function:

```text
P(Y_ij = 1 | θ_i, a_j, b_j) = 1 / (1 + exp(-a_j * (θ_i - b_j)))
```

The scorecard dynamically recalculates `θ_i` post-exam, producing instant mastery radar graphs across curriculum sub-topics.

### 3. 4-Tier Formative Rubric Autograder (`/autograding`)

Traditional automated grading relies on naive exact-match string comparisons or binary pass/fail unit tests. EduPlatform AI implements a **formative neuro-symbolic rubric evaluation model** that assesses subjective essays, mathematical solutions, and source code.

![Teacher Autograding Studio with 4-tier rubric evaluation and personalized revision roadmaps](/static/sst-autograder.jpg)

#### The 4-Tier Evaluation Vector:
Submissions are evaluated against four orthogonal objective criteria:

1. **Conceptual Understanding (`w_1 = 0.40`):** Comprehension of foundational domain theorems, principles, and problem boundaries.
2. **Technical & Analytical Depth (`w_2 = 0.30`):** Mathematical rigor, algorithmic time/space complexity, syntax validity, and edge-case execution.
3. **Critical Thinking & Inquiry (`w_3 = 0.20`):** Novelty of formulation, justification of assumptions, and comparative trade-off reasoning.
4. **Presentation & Structural Clarity (`w_4 = 0.10`):** Cohesion of prose, LaTeX notation cleanliness, code modularity, and documentation.

The composite formative score `S_final` is defined as:

```text
S_final = ∑ (w_k * r_k)    for k = 1 to 4, where r_k ∈ [0, 100]
```

#### Actionable Revision Roadmaps & Educator Verification:
Before any score is permanently recorded, the autograder generates a structured **Growth Action Roadmap** highlighting 3 specific actionable revision steps for the student. Teachers have a **1-click override verification queue** with manual remark attachments to preserve complete human oversight.

### 4. Deep Semantic & Syntactic Originality Engine (`/plagiarism`)

Academic integrity in the generative AI era requires analyzing both verbatim plagiarism and latent AI-generated paraphrasing:

- **Syntactic k-Shingle Indexing:** Computes Jaccard similarity across n-gram token windows to identify verbatim cross-student copying.
- **Dense Vector Embedding Projections:** Embeds submission paragraphs into high-dimensional semantic vector spaces. Cosine similarity between student vector `u` and corpus vector `v` is computed as:

```text
CosineSimilarity(u, v) = (u · v) / (||u||_2 * ||v||_2)
```

- **Zero Public LLM Storage Guarantee:** Compliant with international student privacy protocols (FERPA/GDPR), student submissions are analyzed via ephemeral memory buffers and never retained for public model fine-tuning.
- **Sentence-Level Heatmaps:** Visual color-coded breakdowns distinguish between valid citations, standard technical definitions, and uncredited matches.
